# Gremory Web • Fase 1

Esta atualização inicia a nova identidade do site Gremory com foco em:

- visual mais forte e responsivo
- temática Gremory com detalhes em vermelho e clima dark
- base pronta para módulos futuros
- cards e seções para Charlotte, Pokémon, RPG, Watch Party, Loja e Suporte
- login com opção **manter conectado neste aparelho**

## O que entrou agora

### 1. Nova identidade visual
- fundo mais escuro com detalhes em vermelho
- painéis com visual premium
- padrão sutil estilo escamas no CSS
- layout melhor para celular e PC

### 2. Novo Hub Gremory
Foi adicionada uma área central com módulos:
- Charlotte Hub
- Downloads
- Pokémon
- Watch Party
- RPG Gremory
- Loja & Premium

### 3. Roadmap visível no site
Agora o site já mostra visualmente o que vem nas próximas fases.

### 4. Login melhorado
O login e o registro agora possuem opção:
- **Manter conectado neste aparelho**

Se a pessoa não marcar, a sessão tende a ficar mais controlada no navegador.
