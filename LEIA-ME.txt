GREMORY — PROJETO COMPLETO REVISADO — 27/10/2026
================================================

Este ZIP contém a estrutura completa do site e o bridge compatível. É baseado
no arquivo 'gremory-main (8).zip', no bridge e nas regras de Firebase fornecidos
na conversa. Não aplique patches V12/V13 sobre estes arquivos.

IMPORTANTE: O ZIP NÃO FAZ DEPLOY AUTOMÁTICO. São três instalações separadas:

1) SITE / VERCEL
   - Publique os arquivos desta pasta como o projeto do site na Vercel.
   - Para Jogo da Velha, 21, Forca, Slots, Pokémon via bridge e Charlotte Music,
     o frontend utiliza Firebase Auth + Realtime Database + siteBridgeJobs.
   - NÃO instale FIREBASE_PRIVATE_KEY, FIREBASE_SERVICE_ACCOUNT_JSON,
     FIREBASE_CLIENT_EMAIL ou FIREBASE_DATABASE_URL na Vercel para essas ações.
   - Outros recursos HTTP (downloads, APIs de busca etc.) podem continuar
     utilizando variáveis específicas de serviços externos na Vercel.

2) FIREBASE REALTIME DATABASE
   - Abra Realtime Database > Rules no projeto Firebase já usado pela Charlotte.
   - Publique TODO o arquivo firebase.rules.production.json (não somente partes).
   - As regras negam acesso na raiz e deixam saldo/sorteio/cartas privadas
     sob controle exclusivo do servidor Admin do bot.
   - Faça cópia das regras publicadas antes de substituí-las.
   - NÃO utilize firebase.rules.example.json (modelo antigo).

3) CHARLOTTE — HOSPEDAGEM DO BOT (RAILWAY/HIGHWAY)
   - Substitua database/gremory_site_bridge.js NO PROJETO DO BOT pelo
     arquivo de MESMO CAMINHO incluído neste ZIP.
   - Garanta que o carregamento do bot continua invocando o bridge (como na
     instalação original) e reinicie a Charlotte. Trocar só o bridge dentro do
     projeto do site NÃO altera o bot que está em execução.
   - As credenciais Firebase Admin permanecem SOMENTE no servidor do bot.
   - Continue usando o mesmo banco/projeto Firebase e o mesmo número do bot.

FLUXO CORRIGIDO
---------------
- Login e vinculação continuam utilizando Firebase Auth e o código WhatsApp.
- Jogos grátis (Jogo da Velha / 21 / Forca) não exigem WhatsApp vinculado;
  o bridge gerencia turnos/resultados no Firebase sem movimentar Rúpias.
- Jogos com aposta validam convite, valor e participantes no bridge. Apostas
  antigas não são repetidas silenciosamente.
- Slots: servidor do bot gera o resultado, grava débito/prêmio por ID único na
  carteira do site (siteWallets), e o espelho sincroniza o saldo do bot.
- Música: ativação única por sala, Rúpias debitadas pelo bridge. A música é
  PERMISSÃO da sala, não depende de microfone ou chamada de voz ativa.
- Pokémon: equipes, status e Raid continuam vinculados ao bot.
- O jogo e o site leem resultados e saldo por listeners Realtime do Firebase.
- O espelho financeiro verifica pendências periodicamente e também recebe
  alterações do saldo do bot. Uma rede offline ainda pode gerar atrasos.
- Watch Party, transmissões, microfone separado, personalizações, chat,
  comunidade, notificações e backup/restauração foram preservados.

PROTEÇÃO DOS SALDOS EXISTENTES
-----------------------------
- NÃO apague siteWallets, economyBackups, gameWagers, siteSlotsPending,
  siteSlotsSettlements, ou dados de Pokémon para "destravar" uma operação.
- Se aparecer "giro antigo pendente" ou "operação em análise", confira as
  transações anteriores ANTES de intervir. Um giro antigo pode ter sido
  debitado mesmo sem resposta ao navegador. A correção não cobra de novo.
- Não troque os IDs do projeto Firebase nem vincule uma conta diferente para
  tentar corrigir pendências financeiras.
- Faça backup dos dados do Firebase e dos JSONs do bot antes de publicar.

LIMITAÇÕES DESTA ENTREGA
------------------------
A correção foi verificada por análise do código e testes automatizados locais.
Não houve acesso ao Firebase real, à Vercel nem ao processo ativo do bot.
Portanto, NÃO é possível confirmar cobranças reais, entrega de áudio WebRTC,
ou recebimento de WhatsApp sem publicar e testar na sua infraestrutura.
O site e o bot precisam estar implantados com versões compatíveis.

Se o bot continuar offline, nenhum serviço que dependa do bridge irá responder,
mesmo que a Vercel esteja funcionando perfeitamente.
